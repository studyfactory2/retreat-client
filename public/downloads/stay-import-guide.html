1. 양식을 유지하고 2행부터 입력

시트 이름, 열 순서, 1행의 제목과 빈 셀을 바꾸지 마세요. 셀을 병합하거나 수식을 넣지 마세요.

원본 양식의 열별 입력 내용
열 1행 제목 입력 내용
A 번호 행 번호. 예: 1, 2, 3
B 자원명 해당 시트 이름과 같은 휴양소 이름
C 아이디 원본 명단의 아이디. 없으면 비워 두세요. 앱 로그인 계정은 생성되지 않습니다.
D 이동전화 연락처. 셀 서식은 텍스트로 두어 앞자리 0을 유지하세요.
E 제목 회사명
F / G / H 빈 셀 유지 부서 / 이용객 이름 / 직급. 이름은 반드시 입력하세요.
I 시작일 입실 일시. 예: 2026-11-02 15:00
J 종료일 퇴실 일시. 입실보다 늦어야 합니다.
K 상태 또는 요청날짜 원본의 상태·요청 정보. 상태가 ‘예약’이어도 자동 제외되지 않습니다.
L 빈 셀 유지 메모. 없으면 비워 두세요.

지원 시트: 부산휴양소(해운대), 부산휴양소(기장), 경주휴양소, 애월1호점, 애월2호점, 가평휴양소. 사용하지 않는 시트는 비워 두어도 됩니다.

2. 날짜·시간과 파일 형식 확인

  • I·J열은 날짜/시간 값으로 입력하고, 셀 표시 형식은 yyyy-mm-dd hh:mm으로 유지하세요. 초까지 입력한 값도 지원합니다.
  • 날짜만 있는 행은 앱의 검토 화면에서 시간을 직접 추가해야 합니다. 기본 시간은 자동으로 입력되지 않습니다.
  • 같은 휴양소의 이용 시간이 겹치면 확인이 필요합니다. 이전 퇴실 시각과 다음 입실 시각이 같으면 겹치지 않습니다.
  • Excel 97-2003 통합 문서 (.xls)로 저장하세요. 최대 5MB이며 .xlsx·CSV나 확장자만 바꾼 파일은 지원하지 않습니다.

3. 업로드 후 검토하고 등록 확정

  1. 이용 일정 → 엑셀 가져오기에서 파일을 선택하고 시트를 등록된 휴양소와 연결하세요. 연결은 검토 단계에서도 할 수 있습니다.
  2. 명단 검토하기를 눌러 이름, 연락처, 휴양소, 입·퇴실 일시를 확인하세요. ‘확인 필요’와 ‘오류’ 행은 수정하거나 제외하세요.
  3. 등록 대상이 모두 준비되면 화면의 등록 확인 절차를 진행하세요. 최종 확정 후 이용 일정과 달력에 반영됩니다.
